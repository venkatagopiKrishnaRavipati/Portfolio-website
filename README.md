# Data Atlas — Data Engineer Portfolio

A responsive, single-page portfolio website for **Venkata Gopi Krishna Ravipati**, built with plain HTML, CSS, and JavaScript. The design uses a professional white-and-blue palette, clean typography, subtle gradients, and responsive cards.

## Features

- Responsive navigation with a mobile menu
- Hero section with portfolio introduction and technology highlights
- About and core skills sections
- Featured data engineering project cards
- Professional experience timeline
- Education cards
- Email and LinkedIn contact links
- Scroll-triggered reveal animations
- Reduced-motion accessibility support
- No framework or build step required

## Run locally in Visual Studio Code

1. Download and extract the project ZIP.
2. Open the extracted folder in Visual Studio Code using **File → Open Folder**.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Your browser will open the website on a local development URL.

You can also open `index.html` directly in a browser, although Live Server is convenient while editing.

## Customize the site

- **Content:** edit `index.html`.
- **Colors, layout, and responsive styles:** edit `styles.css`.
- **Mobile navigation and scroll animations:** edit `script.js`.
- **Contact email:** `venkatagopikrishnar@gmail.com`
- **LinkedIn:** <https://www.linkedin.com/in/venkata-gopi-krishna-ravipati/>

The site imports Google Fonts from the web. If fonts cannot load, it falls back to system sans-serif fonts.

## Deploy / host

This is a static website, so it can be deployed to a static hosting provider such as GitHub Pages, Netlify, or Cloudflare Pages.

For GitHub Pages:
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
3. In repository **Settings → Pages**, configure deployment from the `main` branch and root folder.
4. Follow GitHub Pages' status message to open the deployed URL.
