DATA ATLAS — CINEMATIC DATA ENGINEER PORTFOLIO
================================================

Files:
- index.html: portfolio structure and content
- styles.css: responsive professional white/navy/blue theme, subtle blue data globe, clean cards and scroll reveal animations
- script.js: mobile navigation, scroll reveal animations, current year

Run locally:
1. Unzip this folder.
2. Open index.html in a modern browser.
3. For deployment, upload the three files to any static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
